## Development Workflow
1. We are using a Contract-First API approach. Update `api-contracts/` before writing backend logic.
2. Branch naming convention: `feature/[service-name]-[short-description]` (e.g., `feature/inventory-crud`).
3. Never push directly to `main`. Open a Pull Request for review.
